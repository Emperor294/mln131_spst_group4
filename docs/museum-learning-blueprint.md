# SOCIALISM 360 — Museum Learning Blueprint

Phase 4A defines the museum as a pedagogical layer above the existing 3D runtime.
The narrative order is **Explore → Interact → Understand**, with seven freely
explorable zones following the course sequence from Chapter 1 to Chapter 7.

## Planning model

`CourseChapter → Lesson → MuseumConcept → MuseumZone → future 3D binding`

`MuseumConcept` is a concise, source-grounded learning waypoint. It points back
to one or more audited lessons and scoped textbook references instead of copying
full learning sections into a dialog. `implementationStatus: "planned"` means
the concept is defined for future spatial interaction; it does not imply that a
new room, mesh, or runtime interaction exists today.

The lobby is a non-academic entry plan for SOCIALISM 360. It introduces the seven
zones and lets a future experience offer a free choice of learning journey; it is
not a Chapter 0 and does not add a new source claim.

## Artifact distinction

- **Academic concept artifact**: a future purpose-built object that teaches a
  verified MLN131 concept and links to a `MuseumConcept`.
- **Historical/context artifact**: a future contextual object used only after its
  academic provenance has been reviewed.
- **Legacy artifact**: one of the existing nine GLB-bound objects inherited from
  the previous project. These remain functional and `draft`/review-required, but
  are not assigned to a canonical chapter by Phase 4A.

No zone, concept, or artifact receives a GLB mesh binding in this phase.
